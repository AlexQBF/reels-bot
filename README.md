# Reels → Telegram бот (GitHub + Cloudflare Workers, без VPS, без терминала)

Отправляешь боту ссылку на Instagram Reels — получаешь mp4.

## Как это работает

```
Telegram ──webhook──▶ Cloudflare Worker ──▶ поиск прямой ссылки на mp4
                            │
                            └──sendVideo(url)──▶ Telegram сам скачивает и присылает файл
```

Источники перебираются по порядку, первый успешный побеждает:

1. `ig-web` — анонимная веб-сессия Instagram и его GraphQL (так же страницу открывает браузер без логина). Не зависит от embed, поэтому подходит и для совместных публикаций с двумя авторами.
2. `ig-page` — HTML страницы ролика.
3. `ig-embed` — embed-страница.
4. `instafix:…` — зеркала InstaFix из `INSTAFIX_HOSTS`.
5. cobalt — инстансы из `COBALT_INSTANCES`.

Если источник отдал картинку вместо видео, это считается отказом, бот идёт дальше.
Если Telegram не смог забрать файл по ссылке (например, больше 20 МБ), Worker скачивает его сам и загружает (до 50 МБ).

Код деплоится автоматически из этого репозитория: любой коммит в `main` → новая версия воркера.

## Установка (один раз, всё в браузере)

### 1. Бот в Telegram
- `@BotFather` → `/newbot` → имя и username (оканчивается на `bot`) → скопировать токен.
- `@userinfobot` → Start → скопировать `Id`.

### 2. Подключить репозиторий к Cloudflare
1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Workers** → **Import a repository**.
2. Подключить GitHub и выбрать репозиторий `reels-bot`.
3. Project name: `reels-bot`. Build command оставить пустым, Deploy command — `npx wrangler deploy`.
4. **Save and Deploy**. Появится адрес вида `https://reels-bot.ИМЯ.workers.dev`.

### 3. Секреты
Workers & Pages → `reels-bot` → **Settings** → **Variables and Secrets** → **Add**, тип **Secret**:

| Имя | Значение | Обязателен |
|---|---|---|
| `BOT_TOKEN` | токен из BotFather | да |
| `WEBHOOK_SECRET` | любая случайная строка (20–40 латинских букв/цифр) | да |
| `OWNER_ID` | Telegram ID владельца: `/stats`, недельная сводка, уведомления о скачиваниях, подробные ошибки | для статистики |
| `ALLOWED_USER_ID` | если задан — бот отвечает только этому ID; если нет — всем | нет |

Именно тип **Secret**: обычные переменные, добавленные в панели, стираются при следующем деплое.

### 4. Включить вебхук
Открыть в браузере (подставить свой адрес и WEBHOOK_SECRET):

```
https://reels-bot.ИМЯ.workers.dev/setup?key=WEBHOOK_SECRET
```

Должно показать `"ok": true`.

### 5. Проверить
Боту → `/start` → ответит подсказкой. Боту → ссылка на Reels → через несколько секунд видео.

## Статистика (только для владельца)

Нужны секрет `OWNER_ID` и KV-хранилище с привязкой `USERS`.

1. Cloudflare → **Storage & Databases** → **KV**. Если хранилище для бота уже есть — использовать его, иначе **Create** (например, `reels-bot-users`). Скопировать **ID** хранилища.
2. В `wrangler.toml` убрать `#` у трёх строк блока `[[kv_namespaces]]` и вставить ID в кавычки → Commit.

Команды (работают только у `OWNER_ID`, остальным бот про них не отвечает):

| Команда | Что показывает |
|---|---|
| `/stats` | последние 7 дней, включая сегодня: кто сколько раз скачивал |
| `/stats week` | 7 полных дней до сегодня |
| `/stats all` | за всё время |

Раз в неделю бот сам присылает владельцу сводку за прошедшие 7 дней — по расписанию из `wrangler.toml` (`[triggers]`, время в UTC; по умолчанию понедельник 09:00 по Москве). Границы суток задаёт `STATS_UTC_OFFSET`.

Кроме того, владельцу приходит сообщение о каждом чужом скачивании: кто и какую ссылку прислал, получилось или нет. Для этого достаточно `OWNER_ID`, хранилище не нужно. О собственных скачиваниях владельца бот не уведомляет.

Считаются присланные ссылки (запросы на скачивание) и то, сколько из них закончились видео. Подсчёт идёт с момента подключения хранилища. На каждую ссылку — одна запись в KV; бесплатный лимит Cloudflare — 1000 записей в сутки.

## Если ролики перестали скачиваться

Владелец получает от бота подробный текст ошибки по каждому источнику; остальным пользователям приходит короткое сообщение.

- `ig-web: … нет данных` у всех роликов — Instagram сменил идентификаторы запросов (`doc_id` в `src/worker.js`); сверить с актуальными yt-dlp / instaloader.
- `ig-web: … HTTP 401/403/429` или `главная ведёт на логин` — Instagram не пускает адреса Cloudflare.
- «все инстансы отказали» — подобрать новые cobalt-инстансы на https://cobalt.directory (Instagram ✅, без API-ключа и Turnstile) и заменить список в `wrangler.toml`.

## Ограничения

- Только публикации, которые открываются в браузере без входа в аккаунт.
- Надёжность зависит от Instagram и чужих сервисов (InstaFix, cobalt).
- Лимит Telegram для бота — 50 МБ на файл.

## Логи
Workers & Pages → `reels-bot` → **Logs** → **Begin log stream**, затем отправить боту ссылку.
